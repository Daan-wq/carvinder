   → MLHealthStatus
   Check if ML service is running

3. isAvailable()
   → boolean
   Quick true/false availability check

4. getModelStatus()
   → MLModelStatus
   Get model versions and metrics

5. triggerTraining(force?: boolean)
   → { job_id: string, status: string }

ERROR HANDLING
─────────────────────────────────────────────────────────────────────────────

MLServiceError
  - Base exception class
  - statusCode and details properties

MLServiceUnavailableError
  - Network/connectivity failures
  - Always statusCode 503

Retry Strategy:
  - 3 attempts with exponential backoff
  - Backoff delays: 1s, 2s, 4s
  - Retries on: network errors, timeouts, 5xx
  - No retry on: 4xx validation errors
